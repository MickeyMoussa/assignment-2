# assignment-2
## Description
This is a pedagogical portfolio website. This version builds on assignment one in many ways using dynamic js-based operations.
### dynamic content
I used winbox to simulate a mini desktop where people can click on icons and get window pop-ups for info about me and my inspirations. This helps makes the website more interactive
### data handling
the form now validates data and confirms if a message has been sent instead of being static
### animation in error handling
the form now shows errors and helps the user detect where he went wrong in the form-filling process to help them recover
## running
running this web page is straightforward. Simply run the index.html file
